# ГАИ РАДАР — Telegram мини-приложение (by mrsndrp)

Общая карта Мелеуза: люди ставят точки «ПОСТ» / «ПАТРУЛЬ» (с комментарием и фото),
остальные жмут «СТОИТ ✓» или «УЕХАЛИ ✗». Другие города — надпись `soon…`.

## Как работает точка
- Живёт 2 часа. Каждое «СТОИТ ✓» продлевает жизнь на новые 2 часа.
- 3 человека нажали «УЕХАЛИ ✗» — точка пропадает (фото тоже удаляется).
- Один человек — один голос на точку. Новую точку можно ставить раз в 2 минуты.
- Ставить можно только в радиусе 18 км от Мелеуза (меняется в `server.js`, `CITY`).
- Чужие координаты не показываются: на карте видно только свою позицию.

## Запуск
1. Создай бота в @BotFather → `/newbot`, возьми токен.
2. Нужен HTTPS-адрес (Telegram не открывает http). Варианты: VPS + домен, Render, Railway, Fly.io.
   Для теста на своём компе: `cloudflared tunnel --url http://localhost:3000`.
3. Запусти:
   ```bash
   npm install
   BOT_TOKEN=123:ABC WEBAPP_URL=https://твой-домен ADMIN_IDS=твой_telegram_id npm start
   ```
   (свой id можно узнать у @userinfobot). `ADMIN_IDS` — кто может удалять любые точки.
4. В @BotFather → `/newapp` (или `/mybots` → Bot Settings → Menu Button), укажи тот же URL.
   Бот сам ставит кнопку «РАДАР» и отвечает на `/start` кнопкой открытия.
5. Закинь ссылку в беседу: `https://t.me/ИМЯ_БОТА/ИМЯ_APP` (после /newapp) — откроется прямо из чата.

Данные лежат в папке `data/` (на хостинге подключи постоянный диск, иначе точки пропадут при перезапуске;
на Render/Railway это Disk/Volume, путь задаётся через `DATA_DIR`).

## Тест без Telegram
`DEV=1 npm start` → открой http://localhost:3000 (авторизация отключена, только для проверки!).

## Файлы
- `server.js` — API, проверка подписи Telegram, голосования, автоудаление, бот
- `public/index.html`, `style.css`, `app.js` — интерфейс (Leaflet + OpenStreetMap)
