# ГАИ РАДАР (by mrsndrp)

Telegram мини-апп: карта Мелеуза, точки «пост», «патруль», «АЗС», подтверждения «стоит / уехали», анонимный чат.

## Что нового (v2)
- Прицел стоит над нижней панелью и ставит точку ровно туда, куда указывает.
- Кнопки справа переделаны (компас и «я здесь»), слева — чат.
- Анонимный чат: у каждого случайный ник, ссылки и @имена запрещены, у админа есть БАН.
- АЗС: какой бензин есть (92/95/100/ДТ/газ) и очередь; данные рядом сливаются в одну точку.
- Карта вращается пальцами; кнопка «я здесь» включает навигатор, а при движении он включается сам.
- Вблизи (зум ≥ 14) у меток видны подписи и расстояние.
- Рекламные баннеры в чате: массив `ADS` в начале app.js.

## Файлы (все в корне репозитория)
index.html, style.css, app.js, server.js, package.json, README.md

## Обновление
Загрузи на GitHub ВСЕ изменённые файлы (Add file → Upload files), Render пересоберёт сам.

## Переменные на Render
- BOT_TOKEN — токен бота
- ADMIN_IDS — числовые Telegram id админов через запятую
- SECRET — любая длинная случайная строка (для хеширования id; по желанию)

## Заметки
- Геопозиция на сервер не отправляется. Telegram id хранится только в виде хеша.
- На бесплатном Render диск стирается при перезапуске: точки и чат сбросятся.
- Если продаёшь рекламу третьим лицам, по закону её нужно маркировать (erid/ЕРИР).
